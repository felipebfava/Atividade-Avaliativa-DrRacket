# Atividade-Avaliativa-DrRacket
Repositório destinado a atividade avaliativa das disciplinas de Programação Lógica e Funcional e Interação Humana com Dispositivos.

# Utilização
Você poderá ver e avaliar dentro do github, tanto o código quanto o .pdf, porém é recomendável para evitar possíveis erros de visualização, que execute o seguinte comando no terminal, escolhendo um caminho de sua escolha (exe: para salvar na Área de Trabalho, abra o terminal na Área de Trabalho):

```js
git clone https://github.com/felipebfava/Atividade-Avaliativa-DrRacket.git
```

# Imagens
Os arquivos de imagens (.png) foram aquelas utilizadas e estão presentes dentro do arquivo "Artigo_Apresentacao_Avaliacao.pdf", onde consta o modelo SBC feito utilizando LaTeX no editor de LaTeX online chamado Overleaf.

# Código
O arquivo ".rkt" (AvaliaçãoRacket.rkt) é o arquivo do código, utilize um editor de código racket, recomendável a IDE DrRacket para a execução do mesmo. Abra o código na IDE e execute-o.
